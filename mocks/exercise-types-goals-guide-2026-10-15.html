Where you are today — one plan, three different kinds of work

This is your “first edition” plan as it stands. Under each name the app says what it is made of (equipment, muscles). It never says what the exercise is for. And there is nowhere to say what you are aiming at.

What the audit found
  • AThe plan mixes kinds. Four shoulder-control exercises, one hold and two strength lifts sit in one list. The summary counts muscles only, so it cannot tell you the plan is mostly joint control.
  • BA row says what it is made of, not what it is for. “Bodyweight · Core” is equipment and muscle. The “how” is missing.
  • CThe clock icon is the only “kind” the app knows. It marks a hold (L sit). Nothing marks a stretch, a jump or a steadying drill.
  • DA PR is there, a goal is not. “PR 8 reps” counts what you have done. There is no place for “10 in a row”, so you cannot see how far off it is.
One overlap to remove, not add to: Timer already means a hold. If a type sets Timer for you, you never set both by hand.

The five types — your words

Each type is a small drawn symbol and a word. Never a new colour: colour already means muscle group on this page, and one signal per row is the rule. “Could start as” is what a new row would begin with when you pick the type; you can always change it.

Three ways to organise by type

Same seven exercises in each. Goals sits beside the types in all three as a sixth group (the dashed chip).

AA tag on every exercise

Feels like: your plan stays one list in workout order. Tap a type in the summary and the others fade. Cost: nothing is moved or split.

BGroup the list by type

Feels like: a switch above the list, In order or By type. By type is only a view, so the saved workout order is never changed. Cost: one more control.

CPlans on shelves by type

Feels like: each plan belongs to one type. Cost: “first edition” has to be split into one plan per type, and a mixed session becomes several plans.

Goals — what counts, and where it lives

A goal is a target on an exercise, counted from your own log. Pistol squat is a left-and-right exercise, so “10 in a row” would count each leg.

What a goal can be · how the app would know

1On the exercise

Feels like: a goal line under the controls and a small flag on the list row. The bar fills as a logged set gets closer, and a toast says “Goal reached” the moment a set hits it.

2A Goals group of its own

Feels like: every goal as a card with a ring, where it is practised, and a Reached shelf for the ones you have done. Cost: one more place to look.

3Both, with Workout Mode

Feels like: the card in Goals, the flag on the row, and the coach strip in Workout Mode reads “Goal 10 · 2 to go” beside “PR 8 reps” while you train.
